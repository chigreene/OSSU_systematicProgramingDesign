# OSSU_systematicProgramingDesign

## Description
This repo serves as a record of my work through the SPD course on EdX. Systematic Programming Design was a course offered through EdX by the University of British Columbia. The class was offered as Massive Open Online Course (MOOC) in 2015 and persits online [here](https://learning.edx.org/course/course-v1:UBCx+SPD1x+2T2015/home). Grading is not active but the discussion forums remain up and have active contriubers as people work through the course.

My motivation for taking this course is to develope as strong of a foundation in Computer Science as possible as I embark on creating a career in Computer Sciecne and Engineering. My educational road map is the Open Source Society University's Compter Science path. SPD was the first in the Core Programming stack  of course. Naturally I started there. 

The course uses the Beginning Student Language BSL and the IDE DrRacket. The repo contains solutions to the practice problems as well as the quizes and discussion questions. The files in this repo consist of two types, .rkt and .txt. The .rkt files are writen using the fuctional programming language BSL and require DrRacket to read. The other files contain the code exported to .txt files for ease of reading. 

It was helpful for me to identify the distinction between Racket and Beginning Student Language. These are two distict programing languages. DrRoacket IDE can be used for both.
